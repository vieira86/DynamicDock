# AutoDock Vina 1.2.7 (bundled)

Official, unmodified AutoDock Vina v1.2.7 binaries from
https://github.com/ccsb-scripps/AutoDock-Vina/releases/tag/v1.2.7
(Apache License 2.0 — see `LICENSE` in this folder).

They are shipped with Dynamic Dock so a new user doesn't need internet access
or a separate Vina install: `python setup.py` copies the right one for your
OS/CPU to `vina/vina` (`vina/vina.exe` on Windows).

| Folder           | Platform                          |
|------------------|-----------------------------------|
| `windows/`       | Windows 64-bit                    |
| `macos-arm64/`   | macOS Apple Silicon (M1/M2/M3/M4) |
| `macos-x86_64/`  | macOS Intel                       |
| `linux-x86_64/`  | Linux 64-bit (Intel/AMD)          |
| `linux-aarch64/` | Linux ARM 64-bit                  |
